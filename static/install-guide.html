常见问题

Q: 完全不想花钱，能用吗？
A: 能！魔搭GGUF直连完全免费，纯本地运行。通义千问和智谱云模型也有免费额度。
Q: 「一键安装启动.bat」双击闪退？
A: 右键 → 以管理员身份运行。还闪退 = Python 没装（回到第 3 步）。
Q: pip install 卡住了？
A: 国内网可能慢，等 5 分钟就好。或换 pip 源：pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/
Q: 打开 localhost:7000 显示「无法连接」？
A: 等 3 秒刷新，Flask 启动需要时间。看黑窗口有没有报错。
Q: 想切换模型引擎？
A: 设置 → 模型管理 → 魔搭GGUF（默认）/ Ollama（备选）/ 云模型（可选），随时切换。
