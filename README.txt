==============================================
 Harven AI 哈文 - 新手安装指南（请先看这里）
==============================================

【第 0 步：最重要！先解压，再安装】

 把整个压缩包「解压」到一个普通文件夹里（比如 D:\HarvenAI）
 ，然后再双击里面的安装文件。

 ⚠ 千万不要在压缩软件窗口里直接双击 bat 文件！
  那样哈文会被解压到临时文件夹，装一次坏一次，
  看到的"闪一下就没"就是这个原因。


【只有 2 个文件需要你点，其他都不用管】

 1) 安装哈文.bat    ← 第一次用：双击它，装 3~5 分钟
 2) 桌面快捷方式    ← 装完后：桌面会多出鸭子图标「Harven AI」
              ，以后每天双击它就能打开哈文

 文件夹里其他 bat / 文件是升级、修快捷方式用的备用工具，
 平时完全不用碰。


【关于 Python（电脑小白可跳过这段）】

 哈文需要电脑里有 Python 才能跑。
 · 有的话：安装哈文.bat 会自动找到并使用
 · 没有：会自动尝试帮你安装（需联网，1~2 分钟）
 · 自动装失败：屏幕会显示两步手动教程（去 python.org 下载，
  安装时记得勾选「Add python.exe to PATH」），照做后
  再双击一次安装哈文.bat 就行

【常见问题】

 ◆ 双击后"闪一下"就没？
  - 先确认：是不是在压缩软件里直接双击的？→ 先解压！
  - 已经装好、又双击了启动文件？→ 哈文其实在运行，
   会自动帮你打开浏览器页面，窗口消失是正常的。
  - 弹出"是否允许此应用更改设备"（UAC 窗口）？→ 点「是」，
   取消的话哈文启动不了。

 ◆ 装到一半报错 / 卡住？
  - 确认联网正常（第一次装要下载组件）
  - 关掉杀毒软件再试（火绒/360 可能拦截）

 ◆ 想看图文详细教程？
  - 打开文件夹里的「开始使用.html」
  - 或运行哈文后，在对话框输入 /help
