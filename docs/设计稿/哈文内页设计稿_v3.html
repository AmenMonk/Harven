📐 v3 规则与定义（将写入《分项规范》底座）

  • 面板三形态：停靠右栏（默认）/ 独立浮窗（可拖动、可缩放、可多开）/ 全屏——同一个页面的三种摆放，均完整可操作。
  • 大分类 = 生活空间：预置家庭 / 公司 / 个人，可自建（爸妈家、车库、仓库…）；分项是「模块库」待选项，拖进分类=安装实例，同一模块可多实例、数据互相隔离（A 公司账 ≠ B 公司账）；卸载数据保留 30 天。
  • 上传支持：图片（识别）、文档（pdf/word/excel/ppt）、音频 mp3/wav（转文字）、视频 mp4/mov（抽帧识别/素材）、压缩包 zip（技能安装走安全检查）、代码文件——本地先处理，外脑模式下经隐私三档管控。
  • 「监控」→「运行状态」：电脑资源 / 模型加载 / 今日对话与 token 账本 / 安全 / 定时任务 / 健康报告六卡；token 账本直接体现三级火箭效果（B 方案次数单列）。
  • 设置 8→1 单页：模型（卡片化+测一测）/ 安全隐私 / 通用（外观压缩为 3 主题）/ 钥匙串（全部密钥统一）/ 关于；个人画像移「更多」抽屉、插件管理移「更多」抽屉。
  • 开发者模式定义（面向开源社区）：流程编译器 / 工具目录管理（FC 工具启停+token 统计）/ Token 统计 / 实时日志 / 进化提案工坊 / API·MCP 调试 / 数据库只读查看 / 模型高级参数 / 实验性功能。红线：不解除毁灭性命令拦截等安全底线。
