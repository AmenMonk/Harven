📐 v2 设计规范（将写入《分项规范》底座 · UI 章）

  • 图标规范：全局统一一套线性图标（描边 1.8 / 圆角端点 / 22px 栅格），禁止 emoji 与图标混排；哈文品牌形象 = 官方鸭子图标（死命令），龙虾仅作角色名称。
  • 工具格规范：每行 2 格、格高一致；长按拖拽排序，顺序存本地数据库，全组件通用。
  • 按钮规范：胶囊/徽章统一高度 30px、文字不换行、宽度恒定；状态用「文字 + 彩色圆点」表达，不用大 emoji。
  • 输入栏规范：全部视图常驻输入框（聊天/抽屉/垂直工作台），入口只有「＋」和「发送」两个按钮。
  • 回复方三色标注：外脑紫 / 本地绿 / 垂直琥珀，禁止身份冒用。
  • 会话 ≠ 面板数据：新对话只换聊天白纸，面板数据纹丝不动；身份条只显示会话名，模式与面板状态各看各的常驻位。
