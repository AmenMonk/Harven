📐 设计说明（讨论要点）

  • 借鉴来源：OpenClaw（会话优先侧边栏 + Dashboard 小组件 + 对话式配置）、Marvis（状态可视化）、Hermes（本地/云端一键切换常驻）、WorkBuddy（渐进披露：先结论后细节）、扣子（反面教材，不学其复杂度）。
  • 一屏一任务：默认态只有「聊天 + 当前面板」；垂直模型、系统管理都切成独立视图，不与聊天混排。
  • 回复方标注铁规：外脑紫色 🤖 / 本地绿色 🏠 / 垂直模型琥珀色 🌡️ —— 三种颜色三种身份，落实"禁止冒用"。
  • 会话 ≠ 面板数据：新对话只换聊天白纸，面板数据（账本/冰箱/档案）纹丝不动。
  • 右栏三段式：面板 tab（看数据）→ 龙虾工作台（看状态）→ 龙虾发言（被动通知），一栏解决"面板+Agent 可视化+通知"。
  • 设置分级：口头可改的（换模型/开关联网/模式）不进设置页；⚙️ 里只留小白碰不到的高级项。
