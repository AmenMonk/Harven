## 标题
开源了一个本地 AI 大脑，支持三平台 + 中英双语，内置 Python 开箱即用

## 正文

各位 V 友好，

花 3 个月做了一个开源的本地 AI 项目 **Harven AI（哈文）**，想分享一下。

### 是什么

不是又一个 Ollama WebUI，是一个完整的本地 AI 平台：

- **多模型协作**：本地大脑思考 → 外脑（GPT/DeepSeek）分析 → 垂直模型（音乐/图片/语音）执行。不是单模型对话，是多模型分工
- **五重记忆**：对话全量 SQLite 持久化，跨对话不遗忘，越用越懂你
- **受控进化**：AI 能修改自己的代码（你审批后应用，可回滚）。说"帮我加个天气查询"→ 生成提案 → 你批准 → 应用
- **AI 造 UI 面板**：让 AI 帮你生成记账/健身/待办管理面板，iframe 沙盒隔离
- **内置 Python 3.13**：Windows/Linux/macOS 三平台都内置 Python，解压双击就能用，不需要自己装

### 三平台安装包

| 平台 | 大小 | 启动方式 |
|------|------|----------|
| Windows | 16 MB | 双击 .bat |
| Linux | 37 MB | 双击 .desktop |
| macOS | 52 MB | 双击 .command |

全部内置 Python 3.13，解压即用。

### 跟 OpenWebUI / OpenClaw 有什么不同

- **vs OpenWebUI**：OpenWebUI 只是 Ollama 的 Web 界面，哈文是完整平台（知识库+记忆+Skill+面板+协作+市场）
- **vs OpenClaw**：OpenClaw 是"通用数字员工"（连接 50+ 渠道），哈文是"私人管家"（五重记忆+知识库+垂直模型+受控进化）
- **vs ChatGPT**：ChatGPT 数据在云端，哈文 100% 本地，断网可用，永久免费
