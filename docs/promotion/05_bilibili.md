## 分镜脚本

### 0:00-0:15 开场（抓眼球）

**画面**：黑屏，出现文字"如果 AI 能住在你电脑里，会怎样？"

**旁白**：
> 我花 3 个月做了一个开源的本地 AI 大脑——数据在你电脑上，断网能用，而且能自己改自己的代码。

**画面**：GitHub 页面截图，鸭子 logo 闪现，三平台安装包下载按钮

**字幕**：
> 🦆 Harven AI — 本地 AI 大脑
> Windows / Linux / macOS 全平台
> 开源 Apache 2.0

---

### 0:15-0:45 特色一：多模型协作

**画面**：录屏——哈文界面，用户输入"帮我生成一首欢快的背景音乐"

**旁白**：
> 第一个特色：多模型协作。不是单模型聊天，是多个模型分工。
> 
> 比如生成音乐——外脑分析"欢快"的节奏和调性，调 MusicGen 的参数，本地 MusicGen 生成音乐。
> 
> 一个模型搞不定这种任务，但一个团队可以。

**画面**：显示协作流程图
```
外脑分析 → 调参数 → 本地 MusicGen 执行 → 生成音乐
```

**字幕**：
> ☁️ 外脑分析 + 🎵 垂直模型执行 = 协作模式

---

### 0:45-1:15 特色二：五重记忆

**画面**：录屏——打开哈文，问"我上周跟你说要买什么书来着？"

**旁白**：
> 第二个特色：五重记忆。AI 永不遗忘。
> 
> 你跟哈文说过的每一句话都存在 SQLite 里，跨对话不丢失。3 个月后你问"我之前说过什么"，它能回答。
> 
> 不像 ChatGPT，新对话就忘了之前所有事。

**画面**：记忆层级图
```
L0 原始对话 → 全量持久化
L1 任务记忆 → AI 提取关键信息
L2 长期记忆 → 跨对话固化
↑ 主动检索 → 对话时自动拉取
↑ 主人认知 → 记住你的偏好
```

**字幕**：
> 🧠 五重记忆 = 越用越懂你

---

### 1:15-1:50 特色三：受控进化

**画面**：录屏——用户输入"帮我加一个翻译功能"

**旁白**：
> 第三个特色，也是最酷的：受控进化。AI 能改自己的代码。
> 
> 你说"帮我加个翻译功能"，哈文生成代码提案，你看描述，批准就应用，拒绝就不动。
> 
> 能改技能脚本和页面，不能改核心代码。安全。

**画面**：显示受控进化流程
```
用户说需求 → AI 生成提案 → 用户审批 → 应用（可回滚）
```

**画面**：翻译功能出现，用户测试

**字幕**：
> 🧬 受控进化 = AI 自己进化自己

---

### 1:50-2:20 特色四：AI 造 UI 面板

**画面**：录屏——用户输入"帮我做一个记账面板"

**旁白**：
> 第四个特色：AI 帮你造工具。
> 
> 你说"做个记账面板"，AI 生成 HTML/JS/CSS，安装，你就有了新的管理面板。
> 
> 不是对话，是 AI 帮你造 UI。

**画面**：记账面板出现，用户输入一笔账目

**字幕**：
> 🎨 AI 造面板 = 你的专属工具箱

---

### 2:20-2:45 三平台 + 中英双语

**画面**：三台电脑（Windows 笔记本 / Linux 桌面 / MacBook）同时显示哈文界面
