## 一、知识库喂专业资料（最直接有效）

### 方式1：网页上传（适合少量文件）

1. 打开 Harven AI → 左侧栏 → **知识库**
2. 点击「上传文件」
3. 选择你的专业文档（支持 PDF/Word/Excel/TXT/MD/代码文件等 40+ 格式）
4. 等待导入完成（进度条显示）

### 方式2：批量导入脚本（适合大量文件/整个文件夹）

```bash
# 1. 确保 Harven AI 服务器正在运行
#    访问 http://localhost:7000/ 确认

# 2. 批量导入某个目录下的所有支持格式
python import_professional_docs.py "H:\专业资料\医学"

# 3. 只导入特定格式
python import_professional_docs.py "H:\专业资料" --ext=pdf,txt,md

# 4. 先看看有哪些文件（不实际导入）
python import_professional_docs.py "H:\专业资料" --dry-run
```

**推荐目录结构：**
```
H:\专业资料\
├── 医学\
│   ├── 内科学第9版.pdf
│   ├── 药理学笔记.md
│   └── ...
├── 编程\
│   ├── Python核心编程.pdf
│   ├── 数据结构与算法.py
│   └── ...
└── 金融\
    ├── 财务报表分析.xlsx
    └── ...
```

### 方式3：直接粘贴文本（适合零散知识）

在聊天中输入：
```
请记住以下内容到知识库：

[把你的专业资料内容粘贴在这里]
```

AI 会自动调用 `knowledge` 操作将其存入知识库。

## 二、思维链引导（已内置，自动生效）

**无需任何操作。** 现在 AI 遇到复杂问题时会：

1. 先输出 `<think>...</think>` 思考过程（可在界面上看到）
2. 再给出正式回答

**什么时候会触发思考：**
- 多步推理问题（「帮我分析一下...」）
- 代码逻辑问题（「这段代码有什么问题？」）
- 专业分析问题（「从财务角度分析这家公司」）

**什么时候不触发：**
- 简单闲聊（「你好」）
- 明确的事实查询（「今天几号？」）
- 你说「不用解释直接给答案」

## 三、记忆系统智能提炼

### 自动提炼（已内置）

每 10 轮对话，AI 会自动在后台用 Ollama 提炼重要记忆，无需手动操作。

### 手动触发智能提炼

在聊天中输入：
```
请帮我智能提炼一下我们对话中的重要记忆
```

AI 会调用 `ai_consolidate_memories` 功能，返回提炼结果。

### 查看已有记忆

在聊天中输入：
```
你都记住了关于我的哪些信息？
```

## 四、换更强的模型（提升推理能力）

### 当前默认：Qwen2.5-14B（12GB 显存）

适合：日常对话、简单代码、基础推理

### 推荐升级：DeepSeek-R1-14B（同样 12GB 显存）

专门针对推理优化，同样显存但推理能力强很多。

**切换方法（通过 Ollama）：**

```bash
# 1. 下载 DeepSeek-R1 14B（约 9GB）
ollama pull deepseek-r1:14b

# 2. 在 Harven AI 设置 → 模型管理 → 切换到 deepseek-r1:14b
```

### 终极升级：RTX 4090 24GB 跑 32B 模型

如果有预算升级硬件：
- RTX 4090 24GB ≈ 1.5 万元
- 可以跑 Qwen2.5-32B（Q4 量化），推理能力接近 GPT-4
- 或者跑 DeepSeek-R1-32B，推理能力非常强

## 六、常见问题

**Q：导入的 PDF 显示「部分解析失败」？**
A：部分 PDF 是扫描版（图片），需要 OCR。可以把文字版 PDF 重新保存后再导入。

**Q：知识库能存多少内容？**
A：取决于向量数据库大小，一般 10 万段文本没问题。超量后可以删除不需要的资料。

**Q：导入专业资料后，AI 的回答会更专业吗？**
A：会。导入后在聊天中直接问相关专业问题，AI 会优先从知识库中检索答案。

**Q：如何让 AI 在回答时更偏向我的专业领域知识？**
A：在专项培养设置里，加入类似这样的系统提示词：
```
你是一个专业的 XXX 领域助手。
回答时优先参考知识库中的专业资料，
如果知识库中没有相关信息，再基于你的通用知识回答。
```
