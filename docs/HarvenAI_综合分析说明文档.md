## 1. 项目概况

Harven AI（原名灵识/LingZhi）是一款**纯本地运行的私有AI大脑**，专为个人深度使用设计。不同于依赖云端API的聊天机器人，Harven AI 所有数据存储在本地，核心推理在本地Ollama上运行，同时支持多云端模型按需切换。

| 维度 | 数据 |
|------|------|
| **代码规模** | 102 个 Python 文件，30 个内核模块 |
| **前端** | 92KB HTML + 160KB JS + 35KB CSS |
| **API 端点** | 80+ RESTful 接口 |
| **自动化测试** | 43 项全部通过（0.29s） |
| **知识库** | 61 份专业文档已导入（命理风水 + 编程开发） |
| **FAISS 索引** | 7MB 向量索引，1.6MB 元数据 |
| **数据库** | 隐私库 + 过渡库 + 安全库三级物理隔离 |
| **许可证** | Apache 2.0（开源） |

## 3. 功能全景

### 3.1 对话与推理（核心）

| 功能 | 说明 |
|------|------|
| **本地模型推理** | Ollama 运行 Qwen2.5-7B/14B、DeepSeek-R1-14B 等，完全离线可用 |
| **多云模型接入** | DeepSeek / Kimi / 豆包 / OpenAI / Claude / 通义千问，一键切换 |
| **三段式查询** | 知识库RAG → 联网搜索 → LLM推理，自动决策查询路径 |
| **流式SSE输出** | 实时逐字显示，思考过程可见 |
| **消息队列** | AI回复期间不阻塞输入，自动排队处理 |
| **专项培养** | 自定义系统提示词，打造领域专家AI |
| **用户画像** | 6维度自动画像（兴趣/专业/风格/价值观/习惯/情绪） |

### 3.2 记忆系统（五重防失忆）

```
L0 原始对话 → 全量持久化到 SQLite，永不丢失
L1 任务记忆 → AI 语义提取关键信息，结构化存储
L2 长期记忆 → 跨对话的知识提炼与固化
↑
主动检索 → 对话时自动拉取相关历史记忆
主人认知 → 记住用户偏好、身份、习惯
```

- **记忆梦境（Memory Dreaming）**：定期自动整合相似记忆，去重精炼
- **记忆驱逐**：超量记忆自动清理，保持检索效率
- **对话归档**：30天未活跃对话自动归档

### 3.3 知识库系统

| 能力 | 详情 |
|------|------|
| **格式支持** | 40+ 格式：PDF/Word/Excel/PPT/TXT/MD/代码文件/图片OCR等 |
| **检索方式** | FAISS 向量检索 + Rerank 重排序 |
| **自动导入** | 启动时扫描 data/knowledge/ 新文件，后台自动导入 |
| **文本粘贴** | 直接粘贴文本到知识库 |
| **GitHub 导入** | 对话中发送 GitHub URL 自动下载并导入 |
| **元数据分片** | 大文件自动分片，防止单文件过大 |

### 3.4 音视频能力

| 功能 | 实现方式 |
|------|----------|
| 🎤 语音输入 | 浏览器录音 → faster-whisper 本地转写 |
| 🎵 音频上传 | 上传音频文件 → 自动转文字 → AI回答 |
| 🎬 视频上传 | 上传视频 → 提取音轨 → 转文字 → AI分析 |
| 🖼️ 图片上传 | 拍照/上传 → AI视觉分析（需视觉模型） |
| 📁 文件上传 | 通用文件上传，安全扫描后AI处理 |

### 3.5 安全体系（多层纵深）

```
第一层：功德行道德内核 v2.0
  ├── LLM意图复核（非关键词匹配）
  ├── 窗口制计数（每天重置）
  └── 分级锁死（30min → 2hr → 人工）

第二层：网络安全
  ├── SSRF 防护（URL安全校验）
  ├── 速率限制（令牌桶算法）
  └── 文件安全扫描（扩展名+签名双重检测）

第三层：数据隔离
  ├── 隐私库（密码/银行卡等敏感信息）
  ├── 过渡库（外部信息，自动过期清理）
  └── 商用库（可公开分享的内容）

第四层：设备安全
  ├── 硬件指纹（MAC+CPU+BIOS+磁盘+主板五维）
  ├── 设备绑定/解绑
  ├── 防克隆检测
  └── 安全状态监控

第五层：代码执行安全
  ├── Docker 容器隔离（优先）
  ├── 子进程隔离（降级）
  ├── AST 静态分析 + Regex 黑名单
  └── 超时/内存/网络限制
```

## 6. 对比 OpenClaw 龙虾

OpenClaw 是一款开源AI智能体框架，定位为「给AI装上手和脚」，与 Harven AI 有本质定位差异。

### 6.1 定位对比

| 维度 | Harven AI | OpenClaw |
|------|-----------|----------|
| **定位** | 个人专属AI大脑（私人助理） | 通用AI智能体框架（让AI干活） |
| **核心理念** | 私有、安全、懂你 | 开放、可编程、自动化 |
| **目标用户** | 个人用户 | 开发者/企业 |
| **运行方式** | 本地优先，云端可选 | 需要外部LLM API |
| **核心能力** | 深度记忆 + 隐私 + 知识库 | 工具调用 + 工作流 + 多智能体 |

### 6.2 功能对比

| 功能 | Harven AI | OpenClaw |
|------|:---------:|:--------:|
| **本地LLM推理** | ✅ 核心能力 | ❌ 依赖外部API |
| **隐私保护** | ✅ 五层安全 + 三库隔离 | ⚠️ 取决于部署方式 |
| **记忆系统** | ✅ 五重记忆 + 梦境合并 | ⚠️ 基础会话记忆 |
| **知识库RAG** | ✅ FAISS + 40+格式 | ⚠️ 需要自行配置 |
| **多模型切换** | ✅ 一键切换7+平台 | ⚠️ 支持但配置复杂 |

### 6.3 Harven AI 相对 OpenClaw 的优势

1. **隐私至上**：OpenClaw 默认需要外部API（OpenAI等），数据必然流出；Harven AI 核心推理本地完成
2. **开箱即用**：一键启动批处理，OpenClaw 需要大量配置
3. **完整安全体系**：从道德内核到硬件防护的五层纵深，OpenClaw 没有这一层
4. **深度个人化**：五重记忆 + 用户画像 + 专项培养，越用越懂你
5. **丰富的附加能力**：音视频处理、公网分享、手机联动、PWA 等
6. **桌面版原生应用**：PyQt6 原生体验，OpenClaw 只有Web/CLI

### 6.4 Harven AI 相对 OpenClaw 的劣势

1. **工具调用灵活性**：OpenClaw 的工具链更丰富、更灵活
2. **社区生态**：OpenClaw 有更活跃的开发者社区
