# 哈文手机 APP 功能开发文档 v0.1（讨论稿）

> 📅 2026-09-15 · 状态：**讨论稿，待定版拍板后进入开发**
> 🎯 一句话结论：**用 uni-app 一套代码出「安卓 + iOS + 鸿蒙 + 微信小程序」四端 APP，加上已完成的 H5/PWA 版共五个版本；架构上走「局域网直连 + HarvenHub 云中继」双通道，让手机既能在家里当遥控器、出门在外也能远程指挥家里的哈文。**

---

## 1. 定位：哈文 APP 是什么、不是什么

### 1.1 核心认知（先想清楚再动手）

哈文的引擎跑在用户电脑上（本地优先、数据主权），手机 APP **跑不了大模型**（手机算力不够，也违背"装在电脑上的哈文"定位）。所以：

| ✅ APP 是 | ❌ APP 不是 |
|---|---|
| 哈文的**随身遥控器**：出门也能指挥家里的哈文 | 把大模型塞进手机里跑 |
| 手机特有能力的**放大器**：拍照识图、语音对话、推送提醒 | 重新写一个独立的 AI 助手 |
| 家庭场景的**随身入口**：记账、任务、监控提醒随手处理 | 电脑版界面的原样搬运 |

### 1.2 一句话卖点（上架商店用）

> "哈文 APP —— 把你家电脑里的 AI 助手装进口袋。拍照它看、说话它答、大事它提醒，数据始终在你自己电脑上。"

## 3. 技术选型（关键决策①）

### 3.1 四方案对比

| 方案 | 安卓 | iOS | 鸿蒙NEXT | 小程序 | 语言 | 工作量 | 对哈文的适配度 |
|---|---|---|---|---|---|---|---|
| **A. uni-app（推荐）** | ✅ 一键打包 | ✅ 一键打包 | ✅ 官方支持（2024 起出鸿蒙版） | ✅ 直接产出 | **Vue**（哈文 SPA 同款） | ⭐ 1 套代码 4 端 | ★★★★★ |
| B. Flutter | ✅ | ✅ | 🔶 华为官方合作适配中，生态较新 | ❌ 需另做 | Dart（新学） | ⭐⭐ 1+1 套 | ★★★ |
| C. 三端全原生 | ✅ Kotlin | ✅ Swift | ✅ ArkTS | ✅ 另做 | 3~4 种语言 | ⭐⭐⭐⭐⭐ ×3 | ★ |
| D. WebView 壳（SPA 套壳） | ✅ | ⚠️ 纯壳易被苹果拒审 | ⚠️ | ❌ | 前端 | ⭐ 最快 | ★★★ 体验差 |

### 3.2 推荐理由（uni-app）

1. **技术栈零迁移**：哈文 SPA 就是 Vue3，uni-app 的语法、状态管理（Pinia）、甚至不少组件可直接复用——你已有的 38 个 Vue 组件的交互逻辑能搬
2. **一套代码四端产出**，独立开发者性价比最高
3. **国内上架生态最全**：各安卓商店、推送 SDK（ uniPush 对接厂商通道）、隐私合规模板都是现成的
4. HBuilderX 云打包：**没有 Mac 也能出 iOS 包**（用云证书）
5. 免费商用，社区大（DCloud 官方维护，鸿蒙版是华为与 DCloud 合作项目）

> 备选：如果 uni-app 鸿蒙版实际踩坑严重（见 7.2），鸿蒙端退路是"华为官方 ArkTS 复刻精简版（仅对话+推送）"，其余三端不受影响。

## 4. 连接架构（关键决策②）——手机怎么连上家里的哈文

### 4.1 三通道设计

```
┌─────────────────────────────────────────────────────┐
│  模式一 🏠 局域网直连（在家，默认）                     │
│  手机 APP ──────── 同一WiFi ────────> 电脑哈文 :7000   │
│  · 零流量费、零延迟、全功能（含本地模型）               │
│  · 隐私最强：数据不出家门                             │
├─────────────────────────────────────────────────────┤
│  模式二 ☁️ HarvenHub 云中继（出门，杀手锏）            │
│  手机 APP ──> harvenhub.com 中继 ──加密隧道──> 家里电脑 │
│  · 家里电脑的哈文主动连 Hub 挂号（出站连接，免端口映射） │
│  · 消息端到端加密，服务器只过路不存储内容               │
│  · 这是别人没有的能力：出门也能用"自己电脑上的AI"       │
├─────────────────────────────────────────────────────┤
│  模式三 🤖 纯云端直连（应急）                          │
│  手机 APP ──> 外脑 API（DeepSeek/GLM…）直接问答        │
│  · 家里电脑关机时用：只有外脑模式，无知识库/Skill       │
│  · 隐私档位沿用哈文三档（严格/平衡/全量）               │
└─────────────────────────────────────────────────────┘
```

### 4.2 绑定方式（安全）

- 电脑哈文设置页显示**二维码**（含设备令牌，已有 `/api/mobile/qrcode` 接口雏形）
- 手机扫码绑定 → 令牌存手机钥匙串/安全存储 → 可随时在电脑上吊销（已有 `/api/mobile/revoke` 雏形）
- 云中继消息 AES 加密，HarvenHub 服务器**只做转发不看内容**（端到端加密由双方密钥保证）
