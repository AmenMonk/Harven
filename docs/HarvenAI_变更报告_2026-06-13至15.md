## 变更 1：三种查询模式路由规则（engine.py）

**文件**：`src/core/engine.py`  
**行号**：第 920-970 行  
**变更日期**：2026-06-14 定案，2026-06-15 代码实现

### 变更前（文档 v3 状态）
- `direct` 模式外脑不可用时会静默回退到本地 Ollama
- 用户无法区分回复来自外脑还是本地
- 没有"来源标识"机制

### 变更后
```python
# 外脑连接规则（2026-06-14 定案）：
# - direct 模式（用户明确选了外脑）：连接失败 → 报错停止，绝不偷偷用本地顶替
# - auto 模式（自动选最佳）：外脑不可用 → 醒目提示 + 回落本地 Ollama
# - 协作模式：外脑无响应 → 醒目提示 + 纯本地回答

if not use_external and self._query_mode in ("direct", "auto"):
    if self._query_mode == "direct":
        # ★ direct 模式：用户明确要外脑，连不上就报错，不回落
        err_msg = f"❌ 外部大模型（{model_label}）连接不成功..."
        yield ("error", err_msg)
        return  # 直接结束，不用本地 Ollama 顶替
```

**三种模式命名（已更新）**：
- ⚡ `auto` — 自动模式（普通 + 🤝协作子模式）
- 🏠 `kb_only` — 本地模式（原 kb_only，Ollama + 知识库 + Skills，不外传）
- 🤖 `direct` — 外脑模式（原 direct，外部模型主导）

## 变更 2：保密模式（engine.py）

**文件**：`src/core/engine.py`  
**行号**：第 100-103 行、第 175-178 行、第 645-647 行

### 新增逻辑
```python
# 【保密模式】强制锁为本地模式，防止外部网络请求
if self._privacy_mode:
    self._query_mode = "kb_only"
    logger.info("[Engine] 保密模式已激活，强制使用本地查询模式")

# 保密模式下禁止切换查询模式
if self._privacy_mode:
    logger.warning(f"[Engine] 保密模式下拒绝切换查询模式: {query_mode}，保持 kb_only")

# 【保密模式】禁止任何外部调用（包括协作外脑）
if self._privacy_mode:
    logger.warning("[Engine] 保密模式下禁止协作外脑调用")
    return None
```

**效果**：开启保密模式后，无论用户怎么选，系统强制只用本地 Ollama，绝不向外发任何数据。

## 变更 3：极简提示词（engine.py）

**文件**：`src/core/engine.py`  
**行号**：第 974-983 行

### 变更内容
```python
# 文档 v4.1 规则（2026-06-14 修正）：
# - direct 模式 / auto+外部模型路由成功 → 极简（无身份覆盖）— 让外脑做自己
# - auto+回落 Ollama / kb_only / 协作模式 → 完整 — Ollama 需要身份防幻觉
use_minimal_prompt = (
    self._query_mode == "direct"
    or (self._query_mode == "auto" and use_external)
)

if use_minimal_prompt:
    # ★ 极简提示词：零身份覆盖，让外脑以原生身份回答
    # 不包含任何 "Harven AI" / "主人" / "模型调度" 等身份暗示
    system_prompt = """## 行为准则
- 诚实、准确地回答问题
- 不知道就说不知道，不要编造
- 禁止生成色情、暴力、违法内容
"""
```

**效果**：外脑模式（direct）现在 DeepSeek 以自己的身份回答，不会说"我是 Harven AI"。

## 变更 4：模型来源标识（engine.py + app-conversation.js）

**文件1**：`src/core/engine.py` 第 948-967 行  
**文件2**：`static/js/modules/app-conversation.js` 第 718-727 行、第 750-770 行

### 后端改动（engine.py）
每次生成回复前，注入 `model_source` SSE 事件：
```python
# 外脑路由成功时的 thinking 提示 + 来源标识
if self._query_mode == "direct" and use_external:
    yield ("model_source", {
        "model": model_id,
        "label": model_label,
        "is_external": True,
        "mode": "direct"
    })
elif self._query_mode == "auto" and use_external:
    yield ("model_source", {
        "model": model_id,
        "label": model_label,
        "is_external": True,
        "mode": "auto"
    })
elif not use_external:
    yield ("model_source", {
        "model": "local",
        "label": "本地 Ollama",
        "is_external": False,
        "mode": self._query_mode
    })
```

### 前端改动（app-conversation.js）
1. 接收 `model_source` 事件，存入 `window._lastModelSource`
2. 在 `finalizeStream()` 中渲染来源标签：
   - 外脑：**紫色渐变标签** "🤖 DeepSeek · 外脑模式"
   - 本地：**灰色标签** "🏠 本地 Ollama"
