## 第 1 章 产品定位：薄客户端四原则

| # | 原则 | 落地含义 |
|---|------|---------|
| 1 | 只做采集+渲染+推收 | 手机只负责：键盘/语音/相机采集，界面渲染，消息收发。**一切计算、调度、AI 在大脑** |
| 2 | 权限只读 | 权限数据唯一来源=大脑 `/api/my/permissions`，手机零权限判断逻辑 |
| 3 | 命令写死在大脑 | 手机端可做什么由大脑下发的**功能开关表**决定，前端按表渲染显隐 |
| 4 | 不碰敏感存储 | API Key/数据库/密码库永不进手机（配对密钥与恢复码除外，且加密存储） |

## 第 2 章 技术选型（每项给最优解+理由）

| 项 | 选型 | 理由（对比弃选项） |
|----|------|------------------|
| APP 形态 | **v1 = PWA（资质下来前即正式发布形态，零审核当天上线）**；阶段9 = 原生壳（H5 打包） | PWA 零审核零商店上架成本、一套代码桌面/手机共用；原生壳仅为了厂商推送通道与生物锁深度集成，等资质（软著/APP备案）办完再上；界面成果与原生壳完全复用，用户无感升级 |
| 前端框架 | **Vue 3 + Vite + 自研轻量组件库（SPA 组件化界面）** | 新页面形态=**SPA 单页应用**：组件化组织方式替代旧 HTML include 拼接（成品仍是网页技术，HTML 甩不掉，换的是砌墙方法不是砖）；一套代码电脑端+手机 PWA 共用；实证：WorkBuddy=Electron+React SPA，验证 SPA 路线可撑复杂应用，Vue 3 同类更轻、单人上手快；不用重 UI 库（体积/定制性） |
| 状态与通信 | 局域网=直连 HTTP(S)+轮询；外网=云端 WS 中继（阶段3） | v1 先局域网可用，不被阶段3阻塞 |
| HTTPS | **自签证书方案**：大脑首次启动用 mkcert 生成证书，配对扫码时手机安装并信任 | 解决局域网 http 非 secure context 问题（PWA 特性全解锁）；零费用 |
| 语音识别 | **四档分层（v1.1）**：①系统识别（默认，文本上行）②输入法语音（兜底）③传大脑本地 whisper（自选进阶层）④无显卡大脑=CPU small 模型或自动隐藏 | ①②对**全部用户语音不出手机**（识别在手机芯片/用户自选输入法内完成）；③仅对硬件达标者显示——APP 调大脑硬件检测 API 自动判断，不达标整个选项隐藏，不假设用户硬件配置（4070 只是开发者自机，不能当用户默认承诺）；④音频只进用户自己家大脑 |
| 推送通知 | ①**日历双写**（核心保底：remind 任务同步写手机本地日历/闹钟）②Web Push（尽力）③厂商通道（阶段9，需软著/备案） | 国产 ROM 杀后台的现实解：日历双写不依赖任何推送通道 |
| 相机 | 标准 HTML5 getUserMedia + 文件选择器 | 零特殊权限（PWA 内声明用途即可） |
| 存储 | 配对密钥/恢复码用手机 Keystore/Keychain 加密存储 | 系统级安全，不落明文 |

## 第 3 章 信息架构：四 Tab 详设

### 3.1 对话页（首页）

| 区块 | 规格 |
|------|------|
| 顶部芯片组 | 通道状态（🟢局域网直连/🟠云端中继/🔴无法连接，点击看详情）｜查询模式切换（🏠本地/☁️外脑/垂直列表，点击弹半屏切换器）｜🌐联网开关｜协作模式状态（只读显示） |
| 气泡 | 必须标注回复方（"哈文·本地大脑"/"哈文·外脑×"）；AI 消息支持富文本/卡片 |
| 智能面板横滑区 | 已装面板快捷卡 + 虚线空位插槽（点击进面板页） |
| 输入栏 | 📷相机｜文字输入｜🎤语音大按钮（按住说话，松开识别）｜发送 |
| 语音流 | 按住→录音→四档识别（自动降级）→文本确认框→发送（识别失败自动提示"试试键盘上的语音按钮"） |

### 3.2 面板页

Space 切换器（顶部下拉，多空间用户）｜已装面板网格（卡=名称/摘要/状态点）｜虚线空位插槽（从大脑/Hub 装新面板）｜**垂直模型独立区**（医疗等直答面板，与智能面板物理分区，回复方标注规则不变）｜面板详情=加载 manifest.ui.entry（iframe 沙盒）

### 3.3 空间页

Space 名称+类型｜成员列表（头像/角色/在线状态）｜扫码邀请（admin）｜设备列表（每设备：名称/最后在线/当前通道颜色，admin 可长按吊销）

### 3.4 我的页

| 项 | 规格 |
|----|------|
| 我的权限 | 只读渲染开关表（能看什么面板/什么数据级别） |
| 密码保险库 | **独立弹窗输入**（防对话泄密），AI 默认不可见 |
| 配对管理 | 已配对设备列表+吊销；恢复码查看（需生物验证） |
| 定时任务 | 列表/暂停/删除 + **错过待处理列表**（补发/放弃） |
| 连接状态 | 三层通道详情+大脑版本 |
| 设置 | 语音（识别方式/按住说话）、外观（深色模式/字号）、通知（逐面板开关）、流量（仅 Wi-Fi 上传大文件） |

### 3.5 全局组件

- **高危确认卡片**：全屏弹窗+指纹/密码，仅出现在 act 类动作（对外发送/删除/付款）
- **通知中心页**：按空间/来源过滤、need_action 置顶、已读管理
- **首开向导**：3 步（配对大脑→通知权限强引导→恢复码生成）

## 第 4 章 关键流程规格

### 4.1 配对（首次使用）

```
手机打开 PWA → 显示二维码（或输入大脑地址）→ 大脑展示配对码 → 双方确认
→ 密钥交换（libsodium sealed box，大脑签发设备身份密钥）
→ 强制生成恢复码（32位）→ 用户回输其中4位验证 → 配对完成
```

### 4.2 手机丢失恢复

有恢复码：新机输码→大脑验签→旧设备密钥自动吊销→全量重拉。
无恢复码：回家大脑旁扫码重配对（管理员密码批准）→ 旧机吊销，未同步数据接受丢失。管理员可随时远程吊销任意设备。

### 4.3 消息与文件

| 场景 | 通路 |
|------|------|
| 局域网对话 | 直连 HTTPS REST（v1） |
| 外网对话 | WS 中继（阶段3）：消息带 msg_id 幂等去重，断线指数退避重连，协议版本握手 |
| 文件（在家） | 局域网直传大脑 |
| 文件（在外） | 信令走 WS，文件走对象存储预签名 URL 直传，E2E 加密（libsodium），分块+断点续传 |
| 离线（大脑关机） | 顶部🔴"无法连接"，**不回答不转发**，云端零逻辑 |

### 4.4 推送与提醒

大脑创建 remind 任务 → 同步写手机本地日历/闹钟（日历双写）→ 正常路径走推送 → 触发后日历副本自动标记失效。Web Push 仅尽力，日历双写是承诺级。

## 第 5 章 v1 API 端点清单（阶段0 契约冻结对象）

| 端点 | 方法 | 用途 |
|------|------|------|
| /api/chat | POST | 对话（含模式/联网参数） |
| /api/chat/history | GET | 历史消息分页 |
| /api/my/permissions | GET | 开关表+角色+面板列表（见分层管理文档 §7） |
| /api/panels | GET | 已装面板列表（含空位建议） |
| /api/panels/{id}/data | GET/POST/PUT/DELETE | 面板数据 CRUD（空间强制注入） |
| /api/panels/{id}/ai | POST | 面板内"问哈文"（手动分析） |
| /api/notifications | GET/POST | 通知列表/已读/处理 |
| /api/schedule/tasks | GET/POST/DELETE | 定时任务管理+错过列表 |
| /api/pair/qr | GET | 生成配对二维码 |
| /api/pair/confirm | POST | 确认配对（大脑侧） |
| /api/pair/revoke | POST | 吊销设备（admin） |
| /api/recovery/verify | POST | 恢复码验签恢复 |
| /api/upload/presign | POST | 申请中继上传预签名 URL |
| /api/space/members | GET/POST | 成员列表/邀请 |
| /api/status/connection | GET | 通道/大脑状态 |
| /api/calendar/sync | POST | 日历双写登记 |

**协议纪律**：字段名一经冻结不可改，只能加；版本握手 `/api/status/connection` 返回 `protocol_version`。

## 第 6 章 功能开关表（渲染契约）

`/api/my/permissions` 返回示例（手机端唯一渲染依据）：

```json
{
  "user": {"name": "开发者", "role": "owner"},
  "permissions": ["panel.view", "finance.read", "approve.l1"],
  "panels": [{"id":"crm-core","name":"客户管理","visible":true,"readonly":false}],
  "features": {"chat_mode_switch": true, "internet_toggle": true,
               "panel_install": true, "password_vault": true,
               "child_mode": false},
  "protocol_version": "1.0"
}
```

child 账号：`features` 大面积 false，财务/健康面板 visible=false——**这就是"命令写死"的实现**。

## 第 7 章 里程碑

| 里程碑 | 内容 | 验收 |
|--------|------|------|
| PWA-M1 | 对话页+局域网直连+自签证书+配对流程+恢复码 | 手机与大脑真实配对，对话可用，锁屏日历提醒能弹 |

## 第 8 章 红线清单（开发期逐条自查）

1. API Key/数据库/密码库内容不进手机（配对密钥与恢复码除外，Keystore 加密）
2. 权限判断零逻辑——全部按开关表渲染
3. 不提供任何命令执行入口
4. B 类受控数据不落手机本地存储（会话结束即清）
5. 大脑离线=显示无法连接，无任何云端应答
6. 所有对外发送/删除/付款动作必过确认卡片
