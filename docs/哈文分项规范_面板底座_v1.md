## 第 1 章 判定口诀：面板分项 vs 系统级服务

> **有自己的领域数据要长期管 → 面板分项；自己没数据、帮所有面板干活 → 系统级服务**

| 类别 | 清单 | 入口 |
|------|------|------|
| **面板分项**（模块库待选，可拖拽多实例） | 记账 · 食物存储 · 家庭仓储 · 耗材 · 健康 · 教育 · 老人看护 · 宠物 · 车辆 · 智能家居 · 家务缴费 · 保险 · 绿植 · 日程 · **项目工坊** · 文档处理 · 客户 · 库房 · 审批流 … | 面板选择器（左栏【面板】格点开） |
| **系统级服务**（跨领域，跟空间走） | 🕐 时间轴 · ✅ 任务 · 📬 邮箱 · 🔔 通知中心（推送）· 📷 照片识别+照片库 · 🛒 Hub 市场 · 🔍 全局搜索（Ctrl+K）· 🗑 回收站（30 天可恢复）· 🧩 模板中心 | 左栏工具格 / 顶层入口 |
| **不是面板也不是分项** | 聊天主界面 · 运行状态 · 设置 · 模型中心 | — |

- Hub 市场服务端是独立项目（harvenhub.com），哈文内的**客户端界面**是左栏一格；装下来的东西各回各家（面板→选择器、Skill→技能库、知识包→知识库），**Hub 本身不能拖进家庭/公司**。
- 空间切换（家庭⇄公司⇄个人⇄自建）在面板选择器顶部；**切了空间，面板、时间轴、任务标签、照片权限全部跟着切**。

## 第 2 章 空间与大分类（多实例数据隔离）

| 大分类 | 预装 | 说明 |
|--------|------|------|
| 🏠 家庭 | 记账 / 日程 / 家庭物资 / 健康 | 支持多套房子（"爸妈家"单独建，数据隔离） |
| 🏢 公司 | 记账（独立账本）/ 任务协作 / 文档处理 | 支持多家（A/B/C/D 公司各一个） |
| 👤 个人 | — | 只属于 owner 本人，家人数据隔开 |
| ➕ 自建 | 任意组合（车库/仓库） | 大分类本身可自建 |

**多实例铁律**：同一模块拖进不同空间 = 不同实例，数据完全隔离（A 公司的账和 B 公司的账是两本账）。模块默认实例数据不可跨实例复制，只可引用（交叉四铁规见公司文档第 9 章）。

## 第 4 章 统一骨架与三层深度（防"看不懂、记不住"）

**所有面板共用同一个骨架**——学会冰箱 = 会全部面板：

- **第①屏**：总览卡 + **唯一一个大按钮**（冰箱=「拍照入库」，记账=「记一笔」，任务=「＋新任务」）。主功能永远在同一位置。
- **第②屏**：列表/卡片，点哪改哪（微信通讯录的操作感）。
- **第③层·高级**（默认收起）：时间轴开关、权限、规则、导出、待办池……行家才展开。
- **说话兜底**：不会点就说"把鸡蛋记进冰箱"——B 方案关键词直接办，零 token。

**防懵五铁规**（写进底座，任何面板不得违反）：

1. **一致性**：十几个面板一个长相，零记忆成本；
2. **大按钮只有 1 个**：主功能不跟十个功能抢首屏；
3. **点、说、拍**三个动作覆盖 100% 操作，学习成本对标微信；
4. 首次进入 3 步引导 + 示例数据（可一键清空），**之后永不再弹**；
5. **不减功能的实现 = 收起不是删除**：小白用的 20% 占首屏，80% 在「高级」里等行家。

**分项通用标配六件套**：①数据表 ②卡片视图 ③时间轴开关 ④权限标签 ⑤导出 ⑥一句话引导+示例数据。

## 第 5 章 询问提示系统（"要不要我顺便……"）

哈文在干完活（或发现该干的活）之后，主动问一句"要不要我……"。这是填平"AI 有能力做"和"用户知道能做"之间鸿沟的**灵魂机制**。详见《技术详解 v7》§3.35。

### 5.1 三种触发来源

| 来源 | 成本 | 说明 |
|------|------|------|
| ① 规则引擎 | 零 token | 库存低于阈值、卷子批改完成、账单到期 |
| ② AI 攒批窗口 | 每日一次 | 值得主动建议的事项，每晚统一算，打包进晨报 |
| ③ 动作完成即问 | 零额外 | 干完 A 顺手问要不要 B，话术是本次回答自带 |

### 5.2 建议卡统一长相（四要素）与三状态

四要素：**谁（面板名）· 什么事 · 建议做什么（含数据依据）· 采纳后果说明**。四个出现位置（聊天流内 / 面板首屏 / 时间轴 💡 / 晨报）共用同一卡片组件与同一待办池。

状态流转：<span>待回应 → 已采纳（自动执行或过 L2 确认）</span> / 已忽略（同类建议降频）。

### 5.3 两条硬边界

1. **问 ≠ 做**：建议只出卡片，点「好」才动；花钱/对外/删除类点「好」后仍过 L2 确认。
2. **额度制**：每面板每天主动询问 ≤3 条，超额并入晨报一条说完。

### 5.4 防轰炸五规则（全局生效）

| # | 规则 | 解决什么 |
|---|------|---------|
| 1 | **同问三降频**：同类建议被忽略 3 次 → 不再问，沉入「高级→待办池」 | 反复推销 |
| 2 | **打包进晨报**：超额建议合并一条说完 | 弹窗轰炸 |
| 3 | **问≠做**：永远先卡片后动作 | AI 擅自行动 |
| 4 | **完成后不追问**：同一动作链每环节只问一次 | 连环轰炸 |
| 5 | **全局额度共享**：所有面板共用每日池，按优先级排队（健康>缺菜>收纳） | 十个面板各弹各的 |

### 5.5 设置（每面板「高级」区，三行）与账本

开关（开/只在晨报里问/关）· 每日额度（1/3/5）· 安静时段（默认 22:00–7:00，重要级可例外）。运行状态页 token 账本单列一行「询问提示：规则触发 X / AI 攒批 Y」。

### 5.6 全场景清单（V1 参照）

| 面板 | 触发 | 询问示例 |
|------|------|---------|
| 食物存储 | 库存低/临期 | 要出菜谱吗？缺的进购物清单 |
| 家庭仓储 | 换季/入梅 | 下周入梅，要把冬衣收进防潮箱吗？ |
| 健康 | 复查到期/体检入库 | 要出一份给医生看的一页纸摘要吗？ |
| 教育 | 批改完成/错题聚类 | 二元一次没掌握，出讲解+5 分钟练习？ |
| 记账 | 账单/超支 | 房租明天扣款，余额够 ✅；餐饮超预算 12%，看明细？ |
| 车辆 | 里程/年检 | 保养还有 300km，帮你约时间吗（只提醒不代订） |
| 宠物 | 疫苗/粮低 | 疫苗下月到期；猫粮剩 5 天，加购物清单？ |
| 智能家居 | 规则命中 | 连续 3 天忘关客厅灯，建自动关灯规则吗？ |
| 项目工坊 | 阶段完成 | 文案定稿，进入配音环节？（先出 3 版试听） |
| 公司·文档 | 合同审阅完成 | 第 4 条付款条款有风险，出修改建议吗？ |
| 公司·库房 | 低于安全线 | 生成采购单草稿？（L2） |
| 照片库 | 批量入库后 | 这 12 张像团建照片，归公司相册并打标签？ |

## 第 6 章 时间轴（系统级汇流口）

时间轴自己不存领域数据，只把各面板事件**引用**过来按时间排（"引用不复制"）。长度**无限制**——本质是事件库（SQLite，真实时间戳）的视图，向前翻多久、向后排多远都行，"3 个月"只是甘特图常见例子。

### 6.1 三粒度视图（共用同一事件库）

| 粒度 | 形态 | 用途 |
|------|------|------|
| 日 | 24 小时竖轴 | 今天怎么过；💡AI 建议插在对应时段 |
| 月/季 | 日历网格 | 账单周期、考试月 |
| 目标轴 | 甘特横条 | 终点目标→里程碑→配合计划→进度回看（✅/⚠️），偏差时出 💡 建议 |

### 6.2 时间三铁律（AI 不许碰时间）

1. **一切时间来自系统时钟**：过去事件=记录时自动打的真实时间戳（只读）；
2. **AI 只建议日期，写入必须过人**：AI 的日期建议显示为💡待确认，用户点头才成为正式日历事件；
3. **`get_time` 工具兜底**：模型不知道今天几号，需要时调用取真实时间（B 方案零 token），防幻觉日期。

### 6.3 事件设定项（每个事件/规则同一副面孔）

| 设定项 | 选项 |
|--------|------|
| 重复规则 | 一次 / 每日 / 每周几 / 每月几号 / 工作日 / 自定义 |
| 提醒时机 | 准时 / 提前 5 分钟 / 1 小时 / 1 天 / 双重提醒（前晚+当天） |
| 推送通道 | 桌面通知 / 手机 APP / 邮箱 / 全选 |
| 优先级 | 普通 / 重要（强提醒+置顶）/ 静默（只进轴不响） |
| 完成方式 | 手动勾掉 / 规则触发即自动完成 |
| 免打扰 | 22:00–7:00 不推送（重要级可例外） |

### 6.4 定时提示六件套（全规则引擎，零 token）

☀️ 晨报（7:00 今日 3 件事）· 🌙 晚报（21:00 明日预告）· ⏰ 定时提示（吃药 8/12/18 点）· 🔄 周期提醒（每周五倒垃圾/每月 1 号房租/每 5000km 保养）· ⏳ 倒计时（生日还有 3 天）· 🍂 季节触发（入梅晾晒/换季收纳/暖气费）。

**防轰炸**：一天事件太多自动打包进晨报一条，不逐条轰炸。

### 6.5 用户操作（一看就会的三动作）

看（切空间，时间轴跟着切）· 通（面板里一个开关「事件进时间轴」+提前量）· 跳（点事件块直达来源面板条目）。

## 第 7 章 自动运转三层闸门（省 token 的结构性设计）

```
事件/定时触发
 ├─【闸门1】本地规则引擎（零token）：if 库存<阈值 → 直接生成提醒，不过模型
 ├─【闸门2】攒批窗口：多面板待办攒到固定时间窗（如每晚8点）统一跑一轮，共享上下文
 └─【闸门3】AI 干一次重活：分析/写规则/出建议 —— 产出物（规则/结论）存库，
            下次同类情况走闸门1，永不再问模型
```

四原则：①事件驱动，禁止盲轮询 ②AI 写规则一次，规则管日常（批准后永久本地零 token 执行）③攒批窗口共享上下文 ④每面板每日 token 预算，超了自动降级为"攒着等人打开面板再看"。运转日志进运行状态页账本。未来升级位：闸门 3 先本地 14B 试、低置信升外脑；相同问题命中缓存直接复用。

## 第 8 章 数据本地铁律 + 照片识别三通道

**存储与使用分离**：数据 100% 落哈文本地（SQLite + 文件库），外脑只经手"干活必需的最小片段"，用完即走、云端不留底。

| 数据 | 存哪 | 外脑最多收到什么 |
|------|------|----------------|
| 冰箱/衣物/库房照片 | 哈文照片库（按日期+来源）+ SQLite 索引 | 什么都不发（本地识别）或识别后文字小抄 |
| 健康数据 | 本地 SQLite（最高敏感级） | 脱敏摘要（"45 岁男性，减脂目标，今日 1800kcal"），不发姓名/病历原文 |
| 物品位置/账本/孩子记录 | 本地 SQLite | 纯逻辑题（严格档） |

**照片识别三通道**（开机能力探测自动选默认，用户可改）：

| 通道 | 谁识别 | 最低配置 | 隐私 |
|------|--------|---------|------|
| ① 本地识别 | 本地视觉模型 | moondream2（~2GB，8GB 内存纯 CPU）/ Qwen2.5-VL-3B Q4（~3-4GB，低配推荐）/ MiniCPM-V 8B（8GB 显存，强中文） | ✅ 照片不出门 |
| ② 外脑识别 | 豆包/通义/GLM-4V 视觉 API | 有网即可 | ⚠️ 需一次性授权弹窗 + 每张显示去向 + 可随时关 |
| ③ 手动+语音 | 用户自己 | 零要求 | ✅ 完全本地 |

照片统一存**照片库**（知识库页「照片」分类），面板里只放引用不复制。识别后 AI 问一句归属（猜对默认），分流到对应面板（食材→冰箱 / 卷子→教育 / 药物→健康【红线：只记名字+过期提醒，不给用药建议】/ 单据→公司）。技巧提示：弱配置用户拍局部（一层搁架）更准更省。

## 第 9 章 项目工坊（面板分项，多 agent 联合体）

### 9.1 定位

项目型工作的**统一管理台**：协作流水线只是它的"发动机选项之一"——三种用法：①挂流水线全自动（过确认点）②手动让某模型干活，产物照样归档 ③纯手动上传素材管理。工坊里"生成封面"等按钮选项**来自模型中心实际可用清单**（能力探测同一套），每个产出文件自动记录"谁做的"（模型/工具名）= 版权标记数据源。

### 9.2 创作流水线四类节点（编排器模板库一等公民）

| 节点类型 | 干什么 | 例子 |
|---------|--------|------|
| 🧠 模型节点 | 外脑/本地通用/本地垂直 | 写文案、审稿 |
| 🔧 工具节点 | FC 工具/CLI（moviepy、pydub…） | 剪辑、配音、加字幕 |
| 👤 **确认点节点**（硬性） | 流水线暂停等人点头 | 稿子定稿后才能配音；成片确认后才能发 |
| 📦 产物节点 | 中间文件累积 | 自动存项目文件夹 |

**分工铁律**：脑用大模型（内容生成不需要专门工具），手用现成开源库（哈文只造 FC 翻译层，一行轮子不造），用户"自己开发"的方式就是说话——AI 起草 Skill/规则，用户审批（Skill Builder + 受控进化）。

### 9.3 项目文件夹制与版本管理

```
data/creations/<项目名>/
├── 01_文稿/   剧本v1.md → v2.md（AI 写的，标来源+版本，不覆盖）
├── 02_音频/   Suno歌曲.mp3（标：来源·商用授权⚠️）
├── 03_视频/   素材 / 剪辑成片v1 / v2
├── 04_发布包/  成片+文案+封面+各平台尺寸（16:9 / 9:16 / 1:1）
└── 项目.yaml   版本树+谁做的+发布记录
```

版本**只增不覆盖**；来源标记关系钱和法（Suno 免费版不可商用 ⚠️，文件上直接打标）。**发布 V1 一律人工**：备好发布包+一键打开平台网页+复制文案（平台不开放 API，不做自动发布，避开账号风控）。

### 9.4 模板库（一套骨架吃所有项目型工作）

🎬 视频制作 · 📄 文档/标书 · 📣 营销活动 · 🏠 装修项目（家庭）· 🎓 孩子升学 · 💼 求职 · 🛒 大型采购。统一骨架 = **阶段节点 + 确认点 + 产物文件夹 + 版本树 + 来源标记**；新建选模板或一句话让 AI 搭（一次 token），阶段/节点/确认点用户可增删调。

## 第 10 章 事件总线命名规范与面板生命周期

- 事件命名：`模块.事件`（`inventory.low` / `bill.due` / `goal.milestone_missed` / `ask.propose`——询问提示统一走 `ask.propose`，受全局额度管辖）。第三方面板照此发事件。
- 面板生命周期：安装 → 引导（3 步+示例数据）→ 使用 → **停用（数据保留）** → 卸载（二次确认 + 自动打数据导出包）。
- 回收站：面板/事件/文件删除先进回收站 30 天可恢复。

## 第 11 章 Token 经济（引用）

三级火箭：**B 方案关键词（零 token）→ 目录式 FC（小 token）→ 外脑重推理（大 token，只管最难的 10%）**。四落点（工具目录化/结果瘦身/同族合并 61→40/知识库两级+历史分层）见《技术详解 v7》§3.34。**页面多 ≠ token 多**：页面展示与规则引擎均零 token，token 只跟模型对话量有关。
