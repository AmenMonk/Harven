## 任务：只做一件事 —— 把 APK 编译出来

这个包里是完整的 Capacitor 安卓工程（依赖已带全，**不需要 npm install**）。

## 前置要求（服务器需有）

| 项 | 版本要求 | 说明 |
|---|---|---|
| JDK | 17（必须 17，21 不兼容） | JAVA_HOME 指向它 |
| Android SDK | Platform 34 + Build-Tools 34 + Platform-Tools | ANDROID_HOME 指向它 |
| 磁盘 | ≥3GB 空闲 | 首次编译会下载 Gradle 8.x 和依赖 |

## 编译步骤

```bash
cd mobile_app/android
./gradlew assembleDebug --no-daemon
```

- 首次编译 10~20 分钟（自动下载 Gradle 8.7.3 / AGP / 依赖），属正常
- 成功产物：`mobile_app/android/app/build/outputs/apk/debug/app-debug.apk`
- 失败先看报错第一行：SDK 路径问题可在 `mobile_app/android/local.properties` 写 `sdk.dir=/你的SDK路径`

## 回传物

1. `app-debug.apk`（可装测试版）
2. 若编译失败：完整报错日志（`./gradlew assembleDebug --no-daemon > build.log 2>&1` 的 build.log）

## 壳逻辑速览（排障用）

- APP 打开 = www/index.html「连接地址」页（官方鸭子图）
- 记过地址 → 先探测家里哈文（/health，2.5 秒）：在线直连 `http://地址/spa/`（完整版）；不在线走 `https://harvenhub.com/phone?code=配对码`（云端中转）
- **v0.4：存的/填的地址含 harvenhub.com → 直接按云端通道走（?code=配对码），不探测不拼 /spa/**
- 支持 `?server=&code=` 参数扫码直填（code 存 key=`harven_pair_code`）；长按鸭子 3 秒重设地址
- 凭证存 localStorage（key=`harven_server_addr` / `harven_pair_code`）
- 聊天页语音（v0.4 起）：按住说话 = 直接录音上传电脑识别（Whisper），不再调手机系统语音识别
- 聊天页拍照：＋菜单「拍照问哈文」→ Capacitor 相机 → 压缩图进待发预览
